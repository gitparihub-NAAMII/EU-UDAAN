# Skills

What a learner can do after this programme, at three levels of grain.

## The skill pyramid

```
Level 1 · after the whole programme     AI-Native Professional Fluency
                                         "Get original work from AI, delegate repeatable work
                                          to safe agents, and stand behind every output."

Level 2 · after each course              Context Engineering    Agentic Automation   Responsible AI
                                         & Effective Prompting  Design               Governance

Level 3 · after each unit                3–5 named skills per unit  →  skills-by-course.md
```

Below Level 3, each sub-unit has one **primary skill** (for example, C1 2.1 *The Role* →
*Role & Persona Specification*). That mapping lives in `AI_Native_Skill_Mapper.xlsx` and is not
yet in this repo.

## Where the courses come from: four AI-Native skill areas

The programme rests on the **AI Pyramid**: a broad base of *AI Native* capability (everyone who
works alongside AI), a middle layer of *AI Foundation* builders, and a narrow *AI Deep* research
apex. The base is the most important layer, and the pyramid is not a career ladder. This programme
builds the base.

AI Native capability breaks into four areas, and each area is one course:

| Area | What it covers | Status |
|---|---|---|
| **Context Engineering** | Structuring information, instructions and data to guide AI to better outcomes | Course 1, shipped |
| **Agentic AI** | Autonomous task execution, workflow management, goal-directed action | Course 2, shipped |
| **Responsible AI** | Fairness, privacy, transparency; knowing when to constrain or reject AI | Course 3, shipped |
| **AI-Enabled Problem Solving** | Research, analysis, planning and decision support with AI in the loop | Not built ([roadmap](../5-roadmap/course-4-ai-enabled-problem-solving.md)) |

The theory and its sources are in [build manual Part II](../1-how-we-built-it/build-manual.md#part-ii--the-theory).

## Competency levels

Every skill is declared at one of four levels. **These four and no others.**

| Level | Meaning |
|---|---|
| **awareness** | Encountered, can recognise |
| **application** | Can use it in a guided context |
| **mastery** | Can use it independently in new contexts |
| **influence** | Can teach it, extend it, or lead others in it |

Most of this programme targets **application**, and specifically application as a habit: doing it
unprompted in familiar contexts, which sits between application and mastery. Sub-units mark this
with `targets_habit: true`. An older four-point scale (Unaware / Prompted / Habitual /
Transferring) appears in build manual Part IV and is retired; the crosswalk is in
[`_system/vocabulary-map.md`](../_system/vocabulary-map.md) §2.

## The habit loop

For outreach sessions, the three courses compress into five habits:

```
Frame     →  Feed          →  Let it work   →  Verify          →  Own
the task     the right        across steps     before you         the
clearly      context                           trust it           decision
```
