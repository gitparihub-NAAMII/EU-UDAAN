## Promotion

A proposal leaves this directory when it is built, not when it is agreed. Moving it means:

1. The graph files in `_system/graph/` change to reflect it
2. `_system/tools/validate.py` passes
3. `_system/vocabulary-map.md` records the decision if it changed a mapping
4. The file is deleted, and its substance lives in the thing that got built

A proposal that has been agreed but not built stays here. Agreement is not a deliverable.
