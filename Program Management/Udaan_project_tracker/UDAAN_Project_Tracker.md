# UDAAN Project Tracker

_Markdown version of [UDAAN_Project_Tracker.xlsx](UDAAN_Project_Tracker.xlsx), all visible sheets (the hidden "Lists" sheet of dropdown values is left out). Converted 16 Nov 2026 from the Excel last saved 10 Nov 2026. The live tracker is kept on the dashboard under Program Management → UDAAN._

One workbook for goals, weekly plans, targets, to-dos, deliverables, challenges, risks and decisions.

## Sheet: Start Here

| Topic | How to use it |
|---|---|
| Where to type | Type on the sheets Team, Goals, Weekly Plan, Targets, To-Do, Deliverables, Challenges and Risks and Decisions. Every one has ready rows with dropdowns for owner, team, period, status and priority. The Dashboard and the Reached column on Targets are calculated, so leave them alone. |
| Team | One row per person: name, team, role, what they are responsible for, and current focus. Their names then appear in the Owner dropdowns. Match name (yellow) is the short name the Dashboard searches for in Owner columns. |
| Goals | Weekly, monthly, quarterly and yearly goals for every person. Enter Progress as a percentage (for example 25%) and update Status as work moves. A due date in the past turns red until the goal is Done. |
| Weekly Plan | Each week, add what each person will do. Put any date from that week under Week of. The Dashboard counts Monday to Sunday. |
| Targets | One row per person per target. Fill Target and update Actual; Reached shows the percentage with a bar. |
| To-Do | Everyday tasks. Pick an owner and a priority, set a due date, and change Status to Done when finished. |
| Deliverables | Documents, modules, dashboards and reports that must exist when finished, with owner, due date and status. |
| Challenges, Risks | Log what is in the way and what could go wrong, with severity or impact, owner and what is being done. Decisions and follow-ups go on Risks and Decisions. |
| Colours | Status cells are coloured: green for Done, blue for In progress, amber for At risk or Open, red for Blocked or High. Dates in the past that are not finished show in red. |
| Example row | Weekly Plan: 09 Nov 2026 \| Sumi Dhakal \| Collect partner commitments \| Commitments list \| In progress \| Waiting for two partners. |
| Filters | Every sheet has filter arrows on the header row. Use them to see one person, one status or one team. The header row stays in view when you scroll. |
| Private use | This workbook is for one person. The rest of the team works from the Markdown files in the GitHub folder. Update this file from those files, for example before the Monday check-in, and keep a backup copy on OneDrive. |
